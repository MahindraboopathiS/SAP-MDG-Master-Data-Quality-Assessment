SAP MASTER DATA QUALITY CHECKER - GLOBAL SYSTEM ARCHITECTURE
================================================================================

1. SYSTEM OVERVIEW
--------------------------------------------------------------------------------
The SAP Master Data Quality Checker is a production-ready, enterprise-grade 
master data audit, scoring, duplicate detection, and completeness analysis 
framework designed for SAP R/3 (classic ECC / Oracle DB) and SAP S/4HANA 
(HANA DB / CDS / Fiori) environments.

The solution enables SAP Functional Consultants, Data Migration Teams, MDG 
Specialists, and Technical Developers to assess, score, and cleanse master data 
across Material Master (MM), Customer Master (SD/FI), Vendor Master (MM/FI), 
and Business Partner (S/4HANA BP) domains.

3. DESIGN PATTERNS & ENGINEERING PRINCIPLES
--------------------------------------------------------------------------------
- SOLID Principles:
  * SRP: Single responsibility per class (Rules vs. Scoring vs. DB Access).
  * OCP: Abstract rule interfaces allowing dynamic addition of new rules.
  * LSP: ZCL_MDQ_REPO_MOCK seamlessly swappable for ZCL_MDQ_REPOSITORY.
  * ISP: Focused role interfaces (ZIF_MDQ_REPOSITORY, ZIF_MDQ_RULE_ENGINE).
  * DIP: High-level services depend on ZIF_MDQ_REPOSITORY interface.

- Clean ABAP:
  * Strict OO approach (no procedural code or include scripts).
  * Uppercase names for custom Z objects (ZCL_MDQ_*, ZIF_MDQ_*, ZMDQ_*).
  * Class-based exceptions (CX_MDQ_QUALITY_ERROR).
  * Performance: No SELECT inside LOOPs, FOR ALL ENTRIES IN for R/3, HANA Pushdown for S/4HANA.

- Security & Compliance:
  * SAP Application Logging via BAL_LOG_* / CL_BALI_LOGGER.
  * Explicit AUTHORITY-CHECK per business domain (M_MATE_STA, V_VBAK_VKO, F_BKPF_BUK, B_BUPA_GRP).
  * Strict Read-Only mode (NFR-004 & NFR-005).
